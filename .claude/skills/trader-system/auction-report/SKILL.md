## LLM（job='auction'，1 次调用）
- 输入：指数竞价 + 高开榜 + 放量榜 + 连板竞价；
- 输出：{mood, style, hint}（情绪强弱/风格/追涨·低吸·防守提示）；
- 失败 → 规则回退（指数竞价文本）。
