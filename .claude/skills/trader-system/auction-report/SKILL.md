## 数据源
- 指数：腾讯 `qt.gtimg.cn`（9:25 后现价=竞价价，复用 index_realtime）；

## LLM（job='auction'，3 次调用，独立互不影响）
1. `section_analysis_llm`：**各模块竞价解析**（一次调用）——指数/高开放量榜/连板/关键股/核心关注
   每模块一句（原因/影响 30 字内）；该模块竞价无特别消息写"无"→ 展示"（无特别消息）"，不强行解析；
2. `key_stock_llm`：关键股票**板块级**解析（每板块一句，如"受消息影响高开""资金情绪高涨"）；
3. `auction_llm`：**情绪预判** {mood 竞价情绪, style 风格预判, hint 操作提示}（独立，不被解析影响）。

## 模块解析方法论（每模块看什么）
| 模块 | 解析要点 |
|---|---|
| 指数竞价 | 高开/低开结构（小盘 vs 大盘）、放量方向 → 当日风格预期 |
| 高开放量榜 | 高开家数/幅度分布（20cm 多=亢奋）、放量榜资金抢筹信号、低开榜拖累方向 |
| 连板竞价 | 高开率=承接强弱（15/15 全红=情绪强）；低开多=分歧/退潮预警 |
| 关键股票竞价 | 热门板块核心股（**成交量最大关注度最高**，非连板最高——避免与连板节重合）竞价方向 → 板块资金情绪 |
| 核心关注竞价 | 持仓/关注股竞价价与涨幅 → 当日持仓操作倾向 |

## 关键股票选择标准（2026-08-22 v2）
- 前一日涨停股按东财行业（f100，ulist 批量查询）聚合 TOP3 板块；
- 每板块选**昨日成交量最大**的 1-2 只（成交量=关注度代理），**不与「连板竞价」节重合**。

## 复盘闭环（2026-08-22）
- 竞价情绪预判 + 模块解析 → 落库 `viewpoints source='auction_report'`；
- 盘后日报点2 复盘同时纳入竞价预判与盘中观点（来源标注[竞价]/[盘中]分别点评）；
- 复盘 lessions/wrong_reasons → 迭代本 skill（竞价解读方法论随运行进化）。

## 迭代方向
- 竞价量比：f50 异常，后续找专用竞价量比源（或自算 竞价量/昨日全天量 比例）；
- 竞价抢筹候选：高开 + 放量 + 昨日非涨停（今日首板竞价信号）组合筛选；
- 竞价情绪指数：高开家数/连板高开率/炸板竞价 综合成单一情绪分（可沉淀）；
- 模块解析准确率：随盘后复盘积累，校准各模块解析 prompt 约束。
