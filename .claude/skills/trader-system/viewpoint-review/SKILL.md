# 盘中观点复盘

## 触发
盘后日报点2（每日 22:00）。

## 输入
1. **观点**：当日 `viewpoints source='intraday_report'`（B1 盘中报告落库，obj=mood/mainline，
   conclusion=JSON）；
2. **实际**：当日指数涨跌（8 大指数）+ 板块涨幅 TOP5（industry_bars）。

## 输出（JSON）
```json
{
  "verdict": "逐条判断观点对错（对/错/部分对，30字内总结）",
  "wrong_reasons": ["错误原因（分类+具体，每条20字内）"],
  "lessons": ["沉淀成经验的一句话（供固化复盘 skill，每条20字内）"]
}
```

## 错误原因分类（沉淀框架）
| 分类 | 说明 | 应对 |
|---|---|---|
| 数据误判 | 基于滞后/错误数据下结论 | 加强数据新鲜度防守（query_data_freshness） |
| 逻辑缺陷 | 推演链条缺环节（如忽略量能） | 复盘 fixes → 更新 LLM prompt 约束 |
| 突发黑天鹅 | 不可预见外部事件 | 记录但不归责，提示预案留安全边际 |
| 情绪误判 | 情绪周期/连板信号读错 | 校准 emotion_cycle 阈值/输入口径 |

## 输出到报告
- 有复盘结果 → "点2 盘中观点复盘" 节（对错总结 + 错误原因 + 经验）；
- 当日无盘中观点 → 显示"今日无盘中观点可复盘"（不报错）；
- LLM 失败 → 直列观点原文（不阻断报告）。

## 迭代
- `lessons` 积累 → 定期人工审核 → 回填本 skill「经验库」或更新 mood/mainline 的 prompt；
- 目标：盘中判断的准确率可统计（对/错/部分对计数），形成系统能力闭环。
