## A 组：定时/主动推送报告（企微 + 飞书 + 微信多通道，除注明外）

### A0 盘前报告 —— 交易日 08:40（**A1+A2 合并版，2026-08-22**）
- 入口：`scheduler._morning_brief` → `pipeline.notify_morning_brief` → Skill `a0_premarket`（结构化）
  - 8:30 `premarket` 任务保留数据准备（采集+quant+Agent 关注方向落盘 `data/premarket_agent.txt`）
- 内容：**●隔夜外围(表格:美股/A50/日经/韩综/商品/汇率)** ○**外围影响(LLM 解读)**
  ●市场温度 ●仓位/评级 ●市场风格 ●今日关注(Agent 精简,仅结论)
  **●涨停异动监控(表格:停牌+风险提示/异动监控/暴雷)+风险提示**
  ○**消息汇总(宏观仅变化时+个股+市场外+影响解读)**
- 格式：飞书 interactive 卡片（表格组件 + **加粗**，`render_feishu`）；企微/微信纯文本
  （`render_plain`，表格转紧凑行）——表格/加粗仅飞书生效
- 删除项：龙虎榜净买入、指数强弱榜、板块主线、末尾宏观/仓位、Agent 依据/失效条件
- 限频：同 key 10 分钟

### A3 盘后日报 —— 每日 22:00（2026-08-22 重构：盘中报告 PLUS 版，4 点结构化）
- 入口：`scheduler._evening_report` → Skill `a3_daily`（结构化卡片 + 追加【今日】统计/数据质量）
- 结构：
  1. **盘面总览**（收盘）：指数表格 + **指数 ETF 表格**（涨跌幅/成交额/换手/量比/主力净流入/超大单）
     + 大资金进出信号（量比放大/超大单≈国家队）
  2. **盘中观点复盘**：今日盘中报告的预测/建议/短线判断 vs 当日实际 → 对错+错误原因+经验沉淀
  3. **重要板块总分析**：AI硬件/AI软件/机器人/金融/金属/新旧能源/内需 + 各方向 **ETF 验证**
     （纯度高于板块指数）；活跃方向详细、平淡方向一句话中线状态、个股异动一句话归因
  4. **明日预案**：推荐介入（picks）+ 关注/持仓股操作预案（plans）+ **最近 N 日预案质量复盘**
- 尾部保留：持仓警戒 / 消息面(LLM) / 候选池变化
- 预案闭环：点4 落库 `viewpoints source='plan'`（B1 预案对照 + 次日复盘读取）；盘中观点落库
  `source='intraday_report'`（点2 复盘输入）
- LLM：job='daily_report'，4 次调用（复盘/板块/预案/质量），失败回退直列
- 门禁：日线/指数滞后 → 不发送，改推原因（A11）；同 key 10 分钟限频

## B 组：盘中 / 监控告警

### B1 盘中实时报告 —— @机器人 / 私聊 / 语义触发（**120s/人限频**，2026-08-22 v3）
- 入口：`feishu_ws._build_intraday_report` → Skill `b1_intraday`（结构化卡片，默认完整版，
  说"简洁/简短/精简"发简洁版——只留客观盘面，去推演/观点/预案）
- 结构（v3）：
  1. **盘面总览**：指数实时表格 + 大小盘结构 + 指数涨跌幅条形图 + **指数 ETF 大资金信号**
  2. **情绪判断 + 盘面预测 + 短线博弈**（LLM，youzi 方法论）
  3. **日内主线**（LLM）：最强方向 → 原因/内部结构/**板块 ETF 强度**/**推荐关注股票**/龙头/走势推演
  4. **核心关注与预案对照**（点4+5 合并）：核心关注行情表格 + 所属板块补充分析 + 走势推演
     + 盘后预案对照（viewpoints source='plan'）
- 观点留痕：生成后落库 `viewpoints source='intraday_report'`（盘后日报点2 复盘输入）
- LLM：job='intraday_report'，2 次调用（mood / mainline），失败回退规则
- 发送：飞书卡片（表格/图表/加粗）；企微/微信纯文本

### B2 盘中异动推送 —— 交易时段每 10 秒检测（P0/P1，30 分钟/标的限频）
- 入口：`intraday.send_alerts` → `intraday.check_core_moves`
- 内容：●"[P0]【盘中异动】{symbol} 现价 X，较昨收 ±Y%（异动>Z%）" + ○首条 P0 附 LLM 一句话归因(≤50字)
- LLM 参与：归因（`run_trade`，job=intraday）

### B3 P0 监控告警 —— 交易时段每 10 秒检查（边沿触发）
- 入口：`monitor.run_p0_monitor`
- 内容：●[P0]止损触发 / 持仓证伪 / 数据失效(健康→失效通知一次) / 恢复(失效→健康通知一次)
- LLM 参与：无

### B4 LLM 用量告警 —— 单次>2万 / 日累计>50万（1 小时 / 每天限频）
- 入口：`llm._maybe_alert_usage` → `_alert_text`
- 内容：●"⚠️【LLM 用量告警】单次调用 X tokens（超 20,000）/ 当日累计 X tokens（超 500,000）"
- LLM 参与：无（数据来自 LLM 调用记账）

## 已落地改造（第 1、2 点，2026-08-21）

1. **意图识别两级化**（`invest/push/feishu_ws.py`）
   - 新增 `_keyword_report_request`：负向词(历史/周报/新闻等)→直接 no；「名词(报告/行情/盘面/盘口/异动)+限定(现在/今天/实时/来一份…)」→直接 yes；含 6 位代码且无"报告"→ 交 LLM 防误判。
   - `_is_report_request` = 关键词优先 + LLM 语义兜底。绝大多数报告请求（"来一份盘中报告""现在行情怎么样"）零 token、零延迟。
   - 注：此为 2026-08-18「纯语义去关键词」决策的有意回退（体验优先）；测试已同步（`tests/test_feishu_ws.py`）。
2. **会话 Agent 收敛**（`invest/agent/agents.py`）：`run_chat` max_turns 4→3（2 轮工具+1 总结，与提示词"工具≤2次"对齐）。
3. **会话内只读工具结果缓存**（`invest/agent/llm.py`）：同一轮对话内相同(工具,参数)的只读查询（强度/温度/个股日线/联网搜索等 13 个工具）不重复执行，命中直接复用；有副作用工具（写观点/工单/run_skill）不缓存。
4. **关键词识别仅限群聊**（`invest/push/feishu_ws.py`）：`_is_report_request` 新增 `keyword` 开关；`_agent_reply` 新增 `chat_type` 参数，`_handle_event` 私聊(p2p)分支传 `chat_type="p2p"` → **群聊=关键词优先+LLM 兜底；私聊=始终 LLM 语义判断**（不走关键词短路）。
5. 全量 pytest 通过、ruff 0 错误。
