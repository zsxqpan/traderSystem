## 2. 已锁定原则（两块共用）

1. 仪表盘是**盘后复盘**，不是盘中盯盘台。
2. 系统是辅助交易，不靠 agent / 信号自动买卖。
3. 不大改 a0/a7/b1/a3 骨架；不改 a5/a6。
4. 不新增定时 LLM；不为每条信号/动作调模型。
5. 盘中仍以核心池为主；池外只带非常明确的线索。
6. 机构纪律层冻结：凯利、双 Agent、比价主链、BCS/VMS、簇预算——日常栏目不演进。
7. 保留 AI 复盘专栏。
8. 文案：对象+数字+含义一句；禁止「建议买入」。

## 4. 块二 · 动作闭环（阶段 A/B/C 均已写完）

### 4.1 数据（SCHEMA 20：在远程 19 上加动作三表）

**`daily_actions`** PK `(date, symbol)`：每个交易日每个标的一行。盘后写下**下一交易日**。

| 列 | 含义 |
|---|---|
| `verb` | `buy` / `add` / `hold` / `reduce` / `sell` / `wait` / `watch` |
| `priority` | 1 必须 / 2 计划内 / 3 信号 / 4 探索 |
| `source` | `card` / `plan` / `pool` / `signal` / `llm` / `user` |
| 价位 | `entry_lo/hi`、`stop_loss`、`target` |
| `status` | `pending` / `triggered` / `expired` / `done` / `skipped` |
| `position_hint` | 只用 `LEVEL_RISK` / `LEVEL_CAP` 文案，**不算股数** |

**`review_lessons`** PK `(date, kind, body)`：`kind=intraday/plan`。a3 复盘写入，次日注入 `plan_gen`。

**`watch_items`**（阶段 B）：`source=signal/llm_pick/user`；`status=open/promoted/dismissed/expired`；同一 symbol 同时仅一条 `open`（partial unique index）；默认 T+5 交易日过期。

缺表/缺列：查询返回 `[]`，报告该节省略。

### 4.2 合成 `invest/actions/`

| 模块 | 职责 |
|---|---|
| `compose.py` | 规则优先、每标的一行；信号上限 8、picks 上限 3；无 6 位代码的 pick 丢弃；**不写 pool** |
| `persist.py` | 按日 DELETE+INSERT；`update_statuses` 只改 status/现价；`mark_action`；lessons；旧 plan 过期 |
| `query.py` / `format.py` | 只读；`pick_b1` = priority 1–2 + 任何 triggered |
| `watch.py` | 观察名单 CRUD；连续 2 日 signal-watch → `add_watch`；`promote_watch` 只走 `add_to_pool` |
| `digest.py` | 盘中短文本，无 LLM |

合成优先级：破止损 → sell p1；cards 与 plans 价位冲突时 **plan 优先**；LLM 只改 verb/hint，不覆盖价位，不改 priority=1。

### 4.3 阶段 A — 动作表成为操作面

- a3：草稿注入 `plan_gen` → 二次 compose+persist（date=下一交易日）→ 点 4 前「明日动作（规则）」；holdings 带入/止/标/证伪；lessons 落库
- a0：读当日动作表「今日动作」
- a7：核心表加列「动作」「距区间」
- b1：**简洁版也出**动作对照；`update_statuses`
- d33 + `run_section`；周报一行 triggered/expired 计数
- 仪表盘「执行纪律」页顶部只读动作表（阶段 A）；**不加导航**
- `_persist_plan`：先把旧 `source=plan AND obj=plan` 标 expired

### 4.4 阶段 B — 三轨合一 + 观察名单

- P0：`trade_plans` **并** locked/review 且有止损的卡；两源都有止损只推计划# 那一条；拉价宇宙并上这些卡
- b1 `_core_quotes` 与 a7 对齐：池 core/track ∪ 卡
- 连续 2 个交易日 `verb=watch` 且 `source=signal` → 观察名单，**不入池**
- CLI：`scripts/discipline.py watch add|list|dismiss|promote`；`action done|skip <date> <symbol>`
- 仪表盘：完成/跳过、加入观察/驳回/升级 track（升级默认 track，硬门槛仍在 `add_to_pool`）

### 4.5 阶段 C — 盘中 digest

交易日 **10:00、13:30**，`JOB_FUNCS["action_digest"]` 与 `JOB_FUNCS["action_digest_pm"]`（同一函数、**两个 run_slot**），cron id `action_digest_am` / `action_digest_pm`。  
内容：priority=1 且 pending/triggered，外加当日 `triggered`；≤15 行；无 LLM。  
限频：整封 `key=action_digest`，`min_interval=5400`。  
**未改** B2 十秒、未改 core 异动 1800s。

拍板已按此实现：简洁版 b1 出动作表；动作表在执行纪律页顶部；plan 优先；digest 10:00+13:30；池外 watch 阶段 A 就进表、不入池。
