## 0. 已锁定原则（按你的纠正）

1. **仪表盘是盘后复盘工具**，不是盘中盯盘台。使用者不是职业交易员，不会盘中一直开着 Streamlit。
2. **系统是辅助交易，不是量化交易 agent。** 不靠 agent 决定买卖。LLM 当「每日专栏作家」是正确用法：把规则产物与盘面翻译成可读判断。症结是：**辅助对实际交易的帮助不够大**。
3. **现有报告骨架成熟，不大改**，只做优化完善（加节、加列、加素材注入、去重复）。
4. **Token 不搞极限省钱。** 日常定时 LLM 维持现有量级（盘前/竞价/盘中/盘后专栏），控制在个人开发者可承受、不夸张。不加企业级知识库、不加每日深分析、不加每条信号一次 LLM。
5. **信号引擎要全面应用**：报告 + 仪表盘；短线 / 中线分开；不同入口吃不同信号；一期信号不够丰富，要补。
6. **不能只盯核心候选池。** 盘中实时报告（b1）以核心候选池为主，**仅把非常明确的池外信号按需带出**（见 §6.1）；盘前 / 盘后 / 周报 / 仪表盘要看全市场、帮助发现机会。
7. **机构纪律层冻结迭代**：凯利、双 Agent 工单、四套周期镜像当交易输入、簇预算、BCS/VMS、3–5 年比价当买卖依据。代码保留，对话里点名仍可用；日常报告和仪表盘不再演进、也不作为默认栏目。
8. **保留 AI 复盘**（盘中观点复盘、预案质量复盘、周报观点）。不用「只记三条操作」替代。
9. **先方案、审阅通过后再改代码。**

成功标准（辅助变强，而不是自动化）：

- 盘后打开仪表盘，能用信号 + 坐标系回答「市场出现了哪些可跟的方向、哪些该回避」。
- 盘前 / 盘后 / 周报能看到**池外**的机会线索，而不是只给已关注票贴标签。
- 盘中报告仍以核心池为主；池外只出现 action 级明确信号，不被全市场噪音淹没。
- 专栏 LLM 写的内容能引用规则信号（短线结构 + 中线战场），不再靠模型自己发明量价结论。

## 1. 问题重述

一期信号已经能算「保量 / 缩量 / 集体放量 / 空间」，但：

| 现状 | 对辅助的影响 |
|---|---|
| 个股量价规则几乎只扫 `watch`（候选池 + 持仓卡） | 盘前盘后发现不了池外机会 |
| 只有 `auction/intraday/close`，没有中线 horizon | 你最有用的拥挤度×RS 没有变成可复用信号 |
| 只进 a7/b1/a3（a0 一行），仪表盘 / 周报未接 | 复盘和中期看方向用不上引擎 |
| 信号种类偏少 | 报告里「交易信号」节经常空或重复榜单 |
| LLM 专栏与信号两张皮（已开始注入，仍偏短线池内） | 文章可读，但对「去哪发现机会」帮助有限 |

不是报告写得不好，是 **规则产物太薄、投放面太窄、宇宙太小**。

## 2. 总体结构

继续「一次计算、多处消费」，扩展三维，而不是每份报告各写一套阈值。

```
扫描宇宙（分层，仍不全市场扫 K 线）
        ↓
规则引擎  invest/signals/
  短线规则（会话：auction / intraday / close）
  中线规则（会话：daily / weekly；收盘 quant 之后算一次）
        ↓
落库 trade_signals（全量命中）
        ↓
消费方按「入口 × horizon × layer」取子集
  b1 盘中     → 短线 × 关注层为主；发现层仅 action 级明确信号（独立短节，不进核心表）
  a7 竞价     → 短线 × 关注层 + 发现层
  a0 盘前     → 短线未消化 + 中线发现
  a3 盘后     → 短线收盘确认 + 中线发现（注入现有 LLM，不改 4 点骨架）
  a4 周报     → 中线发现
  仪表盘      → 短线+中线，复盘筛选；坐标系为主视觉
  对话 d32    → 按参数取
```

**明确不做（本期）**

- 自动交易、自动入池、每条信号调 LLM。
- 全市场 5000 只逐票扫极致缩量 / 日线形态。
- 重写 a0/a7/b1/a3 结构；新增大报告；改 a5/a6。
- 把仪表盘改成盘中刷新看板。
- 解冻凯利 / 双 Agent / 比价主链到日常栏目。
- 新增定时 LLM 任务（现有专栏次数保持；只把更丰富的信号摘要注入已有 prompt）。

## 3. 数据模型

`SCHEMA_VERSION` 12 → **13**。`trade_signals` 增列（现网 `init_db` 一次）：

| 列 | 含义 |
|---|---|
| `horizon` | `short` / `mid` |
| `layer` | `watch`（候选池+持仓）/ `discovery`（池外发现）/ `market`（市场结构） |
| `name` 等 | 沿用一期 |

主键仍为 `(date, session, signal_id, subject)`。中线用 `session=daily`（每个交易日 quant 后）或 `session=weekly`（周报前可重算，也可直接读本周 daily）。同一标的短线与中线 `signal_id` 不同，不冲突。

`Signal` 数据类同步加 `horizon`、`layer` 字段，默认 `short` + 由宇宙推断的 layer。

查询入口建议：

```text
scan(conn, session, *, horizon=None, layers=None, persist=False, limit=...)
list_signals(conn, date, horizon=..., session=..., layer=...)  # 仪表盘/报告只读库
```

报告预览与 `run_section` **仍不落库**；落库点：

- 短线：现有 `notify_auction` / `notify_after_close`（intraday 报告触发时可选 persist，避免盘中每次 @ 都全量写，可用「同日同 session 覆盖」）。
- 中线：`pipeline` 收盘 quant 成功之后扫一次 `session=daily, persist=True`（失败不阻断报告）。

展示上限按入口不同，不再全局死扣 8 条：

| 入口 | 建议上限 | 说明 |
|---|---|---|
| b1 信号节 | 8～12（池内）+ 最多 5 条发现 action | 盘中要短；发现另列 |
| a7 信号节 | 8～12 | 竞价要短 |
| a3 点1 短清单 | 12 | 收盘确认 |
| a0 / a4 / 仪表盘 | 20～30 | 发现用，可按 severity 分组 |
| 落库 | 全量命中 | overlay / 复盘不丢 |

## 4. 扫描宇宙（分层，发现 ≠ 全市场扫 K）

个人开发者做不到、也不该做全市场逐票精确规则。发现靠 **榜单 + 板块核心 + 涨停结构** 扩宇宙，精确规则只打在这个宇宙上。

| 层 | 成员 | 谁用 |
|---|---|---|
| **关注层 watch** | `candidate_pool` core+track + `cards` locked/review | 所有入口；b1 展示以这层为主（扫描仍含 discovery，见下） |
| **发现层 discovery** | ①昨涨停/连板 ②热门板块成交核心（已有）③当日高开/低开/绝对放量榜 TOP N（竞价/收盘已有榜，转成宇宙而非只展示）④**短线 RS TOP 行业各取成交额最大 1～3 只**（已拍板：个股缩量/放量精确规则**包含**这批股票，避免发现只剩涨停基因）⑤当日龙虎榜标的（有数据才进） | 精确规则打在 ①②④（及⑤入宇宙后的量价）；a7 / a0 / a3 / 仪表盘全量展示；**b1 只取其中 severity=action 的明确命中** |
| **市场层 market** | 涨停池高度/广度/晋级、情绪周期切换、ETF 大资金、拥挤度×RS 象限（hunt/chase/观察/回避**四类都要**）、轮动、板块共振、风格 | 各入口都要；b1 市场层保留（广度/高度/ETF），中线象限不进盘中报告 |

约束：发现层个股精确规则（缩量/放量）**禁止**对全市场 `daily_bars` 循环。宇宙规模目标：关注层 ≤20 + 发现层大约 30～80 只，可接受一次批量行情。

### 5.3 中线（horizon=mid）— 本期重点，几乎全是包装已有 quant

这是把「拥挤度×RS 坐标系」从一张图变成全系统可引用的规则产物。计算放在收盘 quant 之后，读库不联网。

坐标系与仪表盘散点对齐：`rs` 用短线行业 RS，`crowding` 用 `quant_valuation`；竖线 rs=0，横线 crowding=0.8（与现图一致）。另用 `crowding_state` 五态做细化，避免和 0.8 一根线打架：信号文案同时带分位和状态。

**四象限全部落地**（已拍板，不要砍成只要 chase/hunt）：主战场 `quad_hunt`、追高风险 `quad_chase`、观察 `quad_watch_cheap`、回避 `quad_avoid`，外加轨迹 `quad_path`。

| id | 层 | 象限/含义 | 初值 |
|---|---|---|---|
| `quad_hunt` | discovery | **主战场**：rs>0 且 crowding<0.8（优先 crowding_state 正常/升温） | 按 rs 取 TOP，上限 8 |
| `quad_chase` | discovery | **追高风险**：rs>0 且 crowding≥0.8（或高拥挤/极端） | TOP 8 |
| `quad_watch_cheap` | discovery | **观察**：rs≤0 且 crowding<0.8，但 trend_stage 为启动 | TOP 6 |
| `quad_avoid` | market | **回避**：rs≤0 且 crowding≥0.8，或 crowding_state=极端且恶化 | 列出即可 |
| `quad_path` | discovery | **轨迹**：近 5 个交易日从 chase 象限进入 hunt（拥挤回落但 RS 仍正），或反向 | 有则出，帮助复盘「拥挤开始消化」 |
| `stage_start` / `stage_accel` / `stage_slow` / `stage_break` | discovery | 趋势阶段=启动/加速/减速/破位，且为当日变化（昨不是今是） | 变化才出，避免每日重复贴 90 个行业 |
| `rotation_lead` / `rotation_lag` | discovery | `lead_lag` 领涨且 rank≤15 / 滞后且 rank 下滑 | 已有 rotation |
| `sector_resonance` | discovery | 短线 RS TOP15 ∩ 主力净流入 TOP15（即 D29 收成信号） | 最多 5 |
| `style_shift` | market | 已有风格结论较昨日切换（大盘/小盘等） | 有切换才出 |
| `mid_rs_top` | discovery | 周线口径 `period=mid` RS 前 8 且 trend_stage 非破位 | 给周报，日报可 info |

中线信号 **subject_type 以 sector / market 为主**，不在中线规则里点名推荐个股。个股发现仍走：发现层短线规则 + 报告专栏（主线 LLM / 预案 LLM）+ 高开榜。这样不会变成选股 agent。

## 6. 各入口怎么用（报告只完善、不大改）

### 6.1 b1 盘中实时 — 核心池为主，明确发现按需带出

- 结构 4 点不动；LLM 情绪 + 主线 2 次调用保留。
- 规则信号主节：短线 × watch + 市场层（广度/高度/ETF）。
- **发现层按需、只出非常明确的信号**（已拍板）。实现约定：
  - 硬条件：`layer=discovery` **且** `severity=action`（如：发现层极致缩量跌破昨收、高位放量滞涨、板块核心集体高位放量、连板晋级若定为 action）。
  - `watch` / `info` 级池外信号 **不进 b1**（交给 a0/a3/仪表盘和点 3 主线 LLM）。
  - 独立短节「明确发现」，上限 **5 条**，action 优先；**不写入核心关注表**（核心表信号列仍只标池内票）。
  - 无命中则整节省略。
- 简洁版：主节保留；「明确发现」同样保留（否则盘中看不到唯一值得看的池外线索）。

### 6.2 a7 竞价 — 关注 + 发现

- 结构不动（指数竞价 / 信号 / 高开量榜 / 连板 / 核心关注 / LLM）。
- 补 `auction_keep_vol_yoy`；高开/低开放量收成 discovery 信号后，**榜表格仍保留**（成熟栏目），信号节与榜单去重说明一句即可（信号=过精确阈值，榜=发现器）。
- 核心关注表继续信号列；发现层命中出现在信号节，不塞进核心表。

### 6.3 a0 盘前 — 加强「今日看哪里」（发现）

骨架 10 节不动。优化：

- 「昨日未消化」**取消必须仍在监控层**的限制，改为：昨日 `action` 全列，标注是否仍在池内（池外=发现线索）。
- 在「今日关注」附近加一小节 **「市场机会（规则）」**：中线四象限 `quad_hunt` / `quad_chase` / `quad_watch_cheap` / `quad_avoid`（有则出，不必凑满）+ `sector_resonance` / `emotion_stage_shift`（昨日收盘 daily）。纯规则文本，不新增 LLM 调用。
- 8:30 Agent 关注方向保留。专栏继续写外围 / 风险 / 消息。

### 6.4 a3 盘后 — 确认短线 + 发现中线，AI 复盘保留

4 点 + 尾部不动。LLM 4 次 + 条件 ETF 解读保留。

- 点 1 末尾：短线 close（关注+发现+市场）短清单 + 中线 daily **四象限**分组（hunt/chase/观察/回避，有则出；规则，几行）。
- 点 2 / 3 / 4 的 prompt **注入** 上述摘要（已有 `signals_text` 渠道加长）：让复盘、板块分析、明日预案能引用四象限与池外放量核心，仍禁止模型自己编造保量/缩量/象限。
- 预案 LLM 继续覆盖持仓/核心池；picks 继续允许系统探索池外（现口径），但 picks 应优先落在 `quad_hunt` 或当日 discovery 短线命中的行业里——用 prompt 约束，不当硬闸（避免没信号就空预案）。

### 6.5 a4 周报 — 中线发现

骨架不动（评级/温度/中线强度/低估值/宏观/周期/消息/观点）。增加一节 **「中线信号」**：`mid_rs_top`、四象限 `quad_*`、`rotation_*`、`stage_*` 本周累计或周五 daily。D30 周期定位保留。

**a5 月报、a6 年报本期完全不动**（已拍板）。不接短线、不加中线信号节、不改 LLM。

### 6.6 仪表盘 — 盘后复盘 + 发现（不是盯盘）

现有「拥挤度×RS」继续当总览主视觉，这是已验证最有用的一块。完善：

1. **散点**  
   - hover 增加 `crowding_state`、是否命中 `quad_*`。  
   - 点形状或颜色区分：仅行业 / 行业且命中中线信号。  
   - **本期不做盘中自动刷新**；数据仍是收盘 quant 快照。  
   - 轨迹（`quad_path`）：可用浅色箭头或附表「近 5 日象限变化」，不必上动画。

2. **新页「交易信号」**（已拍板：加独立页；盘后筛选，默认最近一个交易日）  
   - 筛选：horizon（短/中）、session、layer、severity。  
   - 表：时间、对象、名称、含义、证据数字。  
   - 这是信号全面应用的主复盘入口。

## 10. 测试与风险
